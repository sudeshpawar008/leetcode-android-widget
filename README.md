LeetCode Android Widget 📱

An Android home-screen widget that displays LeetCode problem information to help developers stay consistent with daily problem-solving practice.

📌 Features

Displays LeetCode-related content directly on the home screen
Lightweight and minimal design
Updates automatically via widget refresh
Built using modern Android development tools

🛠 Tech Stack

Language: Kotlin
Build System: Gradle (Kotlin DSL)
IDE: Android Studio
Min SDK: As configured in the project

🚀 Getting Started
Prerequisites
Android Studio (latest stable)
Android SDK installed
Internet connection (if API integration is added later)

Steps

Clone the repository:
git clone https://github.com/sudeshpawar008/leetcode-android-widget.git
Open Android Studio
Select Open an existing project
Choose the cloned project folder
Let Gradle sync complete
Run the app on an emulator or physical device

🧩 How to Use the Widget

Install the app on your device
Long-press on the home screen
Select Widgets
Drag LeetCode Widget to the home screen
Resize if needed
